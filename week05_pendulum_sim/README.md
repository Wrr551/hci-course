## 实验总结与三反思

1. 意图清晰度反思：
在让 AI 编写单摆代码时，我一开始没有指定具体的参数（如滑块范围）。后来补齐了“角色+目标+约束+验收标准”的四段式 Prompt，告诉 AI 必须包含摆长、重力、阻尼等滑块，并且点击重置要回到 45 度。补齐约束后，AI 直接生成了带拖尾、能量条的完整版，这让我认识到高确定性 Prompt 的重要性。

2. 闭环控制反思：
在任务四中，我故意在按钮上写了一个不存在的 `bugTest()` 函数，浏览器控制台立刻抛出了 `Uncaught ReferenceError`。我没有盲目让 AI“重写一遍”，而是按 F12 复制了完整的红字错误堆栈喂给 AI。AI 通过 Reflection 准确指出了“内联 onclick 与内部闭包作用域不匹配”的问题。我看懂了它的修复方案，并成功把代码改回绑定方式，最终控制台 0 报错。

3. 主体地位确认：
作为 HOTL（人在回路之上）的总设计师，我决定了产品的核心视觉（深灰科技背景、发光效果）和交互逻辑（滑块联动、重置位置）。而 AI 承担了繁重的重复劳动，比如写出 400 多行的 Canvas 渲染代码、物理微分方程计算和 UI 样式搭建。我负责“提需求、看效果、抓报错”，AI 负责“写代码、干苦力”。
